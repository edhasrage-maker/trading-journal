The rules behind itwhat changes in the prompt, not just the layout
Prompt changes
  • Scale to the day. Line budget derives from trade count — 1–2 trades gets ≤3 lines, not ≤16.
  • Ban restatement. A line may not assert a tag the trader set or a point they made in their notes. Both are in the prompt already; neither is currently forbidden.
  • Every line carries evidence — a number, an n, or a comparison to their own history. No adjective-only lines.
  • Drop "patterns across trades" under 3 trades. There are none.
  • Four bullet arrays collapse to one ranked list, tone marked, so the model can't pad a thin section to hit its quota.
  • Verify tags and notes against the tape. Today's live output asserted "zero MAE at entry confirms pristine entry timing" — the recorded MAE is 1.75 points, 78% of the stop. It repeated the trader's note instead of checking it.
What it needs to be good
  • Tag-level baselines (revenge −0.24R × 44, Stable +0.72R × 90) — computed today only by ad-hoc query, not fed to the prompt. This is the real build.
  • Heat/capture baselines — the split just shipped, reusable here.
  • The coaching thread's standing directives, already passed in.
